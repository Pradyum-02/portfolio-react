# ⚙ Getting Started

Clone the repository

```bash
git clone https://github.com/Pradyum-02/portfolio-react.git
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build production version

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
